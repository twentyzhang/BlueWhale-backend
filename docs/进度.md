### 模块十四：AI 语义搜索（SemanticSearchService）

> AI-1。独立于关键词搜索的语义检索链路：transactional outbox 同步「商品变更 → 向量索引」+ Qdrant 向量库 + 通义 `text-embedding-v3`（1024 维）。

| 方法 / 任务 | 接口 / 目的 | 状态 |
| --- | --- | --- |
| `search` | GET `/api/products/semantic`（开放，失败降级关键词搜索） | 完成 |
| `reindexAll` | POST `/api/admin/products/reindex`（Admin 全量回填） | 完成 |
| 商品写入队 outbox | `ProductServiceImpl` create/update→UPSERT、delete→DELETE（同事务） | 完成 |
| 中继同步 | `OutboxRelayJob` 每 5s 轮询 PENDING → embed → 同步 Qdrant | 完成 |

**关键能力：**
- **方案 C transactional outbox**：商品写与 `index_outbox` 事件同事务原子提交；中继异步消费，AI 基础设施不可用不影响商品写（事件留 PENDING 重试）。
- **幂等 + 至少一次投递**：Qdrant 以 `productId` 作 point id，upsert/delete 天然幂等；失败重试 ≤ maxRetry(5) 超限置 FAILED；Qdrant 不可用整批跳过下轮重试。
- **过滤下推**：分类/价格作 Qdrant payload 过滤在向量库侧筛；命中按 score 重排回表。
- **优雅降级**：embedding/Qdrant 失败回退 `ProductService.searchProducts` 关键词搜索。
- **零新增 Maven 依赖**：Spring `RestClient` 直调 Qdrant/通义 REST。
- 数据迁移：`V7__index_outbox.sql`。embedding 文本 = 商品名 + 类目名（`product` 无描述字段，留作后续加固点）。

**关键能力：**
- **手写 Agent 循环**：非流式工具轮（LLM 输出 `tool_calls` → `ToolRegistry.execute` → 回填 tool 结果）重复最多 `maxRounds=5` 次，超出推 `error`；最后一轮调 `streamFinal` 流式生成最终回答；客户端断开（`SseEmitter.onCompletion`）设每请求局部 `AtomicBoolean` 标志，短路剩余轮次省 token。
- **SSE 事件协议（与 RAG 不同）**：`step`（工具执行前，说明意图）→ `tool`（工具结果 ok）→ `products`（命中商品卡，4 个只读商品工具触发）→ `answer`（流式 token，多次）→ `done`；异常/超轮数推 `error`。
- **6 个工具，越权防护**：4 个公开只读工具无需身份；`get_my_orders`/`list_my_coupons` 两个个人数据工具强制从 `ctx.userId()` 过滤，LLM 无法绕过、也无法访问他人数据。
- **限流**：拦截 `/api/assistant/chat`、`/api/products/qa`、`/api/products/semantic` 三端点；超限 `BusinessException(429)` → `GlobalExceptionHandler` 转 `Result{code:429}`（HTTP 200 是项目约定）。
- **熔断/重试**：embedding `@CircuitBreaker(aiEmbedding)+@Retry(aiEmbedding,max=2)`，fallback 返 `float[0]` → `SemanticSearchServiceImpl` 自动降级关键词搜索；LLM `@CircuitBreaker(aiLlm)` fallback 抛 `IllegalStateException` → 上层 catch 推 SSE error。`TongyiEmbeddingClient` 补 `SimpleClientHttpRequestFactory` connect/read 超时（30s，`search.timeout-ms` 可覆盖），防 DashScope 挂起阻塞线程（终评 must-fix，熔断/重试只防已完成失败、不防在途挂起）。
- **监控**：`management.endpoints.web.exposure.include=health,prometheus`；`/actuator/health` 在 `SecurityConfig` 中 `permitAll`，`/actuator/**` 其余 `hasAuthority("ADMIN")`（注意是裸串，因 `JwtAuthenticationFilter` 以 `SimpleGrantedAuthority` 存无前缀 role）。
- **无新增数据库迁移**：Agent 只读既有表，Flyway 仍停留在 V7。
- **新增 4 Maven 依赖**：`resilience4j-spring-boot3:2.2.0`、`spring-boot-starter-aop`、`spring-boot-starter-actuator`、`micrometer-registry-prometheus`。
