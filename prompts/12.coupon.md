请实现 CouponGroupServiceImpl 和 CouponServiceImpl 中的所有方法，
参考 docs/api-spec.md 中优惠券相关接口定义。

CouponGroupServiceImpl 需要实现以下方法：

1. listCouponGroups（GET /api/coupon-groups）：
    - 无需登录
    - 只返回 remainCount > 0 且未过期（expireAt 大于当前时间）的优惠券组
    - 分页返回，响应字段：id、name、type、value、minOrderAmount、
      expireAt、totalCount、remainCount、storeId、storeName
    - storeId 为 null 的为全局优惠券，storeName 返回 null

2. createStoreCouponGroup（POST /api/stores/{storeId}/coupon-groups）：
    - 仅 Staff（本店），使用 AuthUtil.requireRole("STAFF")
      和 AuthUtil.requireStoreAccess(storeId) 校验
    - startAt 不能晚于 expireAt，否则抛出 BusinessException
    - totalCount 必须大于 0
    - DISCOUNT 类型的 value 必须在 0 到 1 之间（不含 0 和 1）
    - AMOUNT_OFF 类型的 value 必须大于 0
    - 创建时 remainCount 初始值等于 totalCount
    - 返回新建优惠券组的 id

3. createGlobalCouponGroup（POST /api/coupon-groups）：
    - 仅 Admin
    - 其余校验同 createStoreCouponGroup
    - storeId 存为 null
    - 返回新建优惠券组的 id

4. deleteCouponGroup（DELETE /api/coupon-groups/{groupId}）：
    - Staff 只能删除本店优惠券组，Admin 可以删除任意优惠券组
    - 优惠券组不存在则抛出 BusinessException（code 404）
    - Staff 删除全局优惠券或其他店铺优惠券时抛出 BusinessException（code 403）
    - 已有用户领取过该优惠券组时不允许删除，抛出 BusinessException
    - 返回 Result.success()

CouponServiceImpl 需要实现以下方法：

5. claimCoupon（POST /api/coupon-groups/{groupId}/claim）：
    - 仅 Customer
    - 优惠券组不存在则抛出 BusinessException（code 404）
    - 优惠券组已过期则抛出 BusinessException
    - remainCount 为 0 则抛出 BusinessException（提示"优惠券已被抢完"）
    - 同一用户对同一优惠券组只能领取一次，重复领取抛出 BusinessException
    - 通过以上校验后：
      将 coupon_group 的 remainCount 减 1
      创建一条 coupon 记录，状态为 UNUSED
    - 以上两步需在同一事务中完成，加 @Transactional 注解
    - 返回新建优惠券的 id

6. getMyCoupons（GET /api/coupons/mine）：
    - 仅 Customer
    - 支持按 status 筛选（UNUSED / USED / EXPIRED），不传则返回全部
    - 不分页，返回列表
    - 响应字段：id、groupName、type、value、minOrderAmount、
      expireAt、status、storeId
    - 已过期但状态仍为 UNUSED 的优惠券，返回时 status 显示为 EXPIRED
      （不需要更新数据库，只在查询结果中处理）
