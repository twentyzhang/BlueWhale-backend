1. listAddresses（GET /api/addresses）：
    - 仅 Customer，使用 AuthUtil.requireRole("CUSTOMER") 校验
    - 返回当前用户的所有地址列表（不分页）
    - 响应字段：id、receiverName、phone、province、city、
      district、detail、isDefault
    - 默认地址排在列表第一位

2. createAddress（POST /api/addresses）：
    - 仅 Customer
    - 如果 isDefault 为 true，需将该用户其他地址的 isDefault 改为 false
    - 如果当前用户还没有任何地址，无论 isDefault 传什么值，
      都自动设为默认地址
    - 返回新建地址的 id

3. updateAddress（PUT /api/addresses/{addressId}）：
    - 仅 Customer（只能操作自己的地址）
    - 地址不存在则抛出 BusinessException（code 404）
    - 地址不属于当前用户则抛出 BusinessException（code 403）
    - 只更新请求体中传入的字段，未传入的字段不修改
    - 如果将某地址设为默认（isDefault 改为 true），
      需将该用户其他地址的 isDefault 改为 false
    - 返回 Result.success()

4. deleteAddress（DELETE /api/addresses/{addressId}）：
    - 仅 Customer（只能操作自己的地址）
    - 地址不存在则抛出 BusinessException（code 404）
    - 地址不属于当前用户则抛出 BusinessException（code 403）
    - 删除的是默认地址时，自动将该用户最新创建的一条地址设为新默认地址
      （如果删除后没有地址了则不处理）
    - 返回 Result.success()
