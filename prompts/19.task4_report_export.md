下一阶段路线图任务 4：报表导出 Excel。
背景见 docs/下一阶段路线图.md，选型记入 docs/重要决策说明.md（#48），
导出流程记入 docs/实现说明.md，接口变更同步 docs/api-spec.md。

请在现有报表 JSON 接口基础上增加 xlsx 导出：

1. 依赖：引入 EasyExcel（com.alibaba:easyexcel:3.3.4，比 Apache POI 轻、注解式）

2. 新增两个导出接口（复用现有 ReportService 查询，自带鉴权 + 缓存）：
   - GET /api/stores/{storeId}/reports/orders/export（Staff 本店）
   - GET /api/admin/reports/orders/export（Admin）
   - query 同对应 JSON 报表接口（startDate/endDate 可选）

3. 多 Sheet 工作簿：
   - 门店：汇总（总订单数/总收入/均单价）/ 状态分布 / 每日收入
   - 全局：汇总（总订单数/总收入）/ 门店分布 / 每日收入
   - 行模型放 dto/excel/，用 @ExcelProperty 注解列名

4. 关键约束：
   - Controller 先调 Service 查数据（鉴权失败在此抛异常、正常落 JSON 错误体），
     再设响应头并写字节——保证鉴权失败不产出半截损坏文件
   - 导出转换逻辑（DTO→xlsx）放 util/ReportExcelExporter（纯转换、不碰鉴权/HTTP），
     下载响应头由 util/ExcelDownloadUtil 设置
   - Content-Type 为 xlsx，Content-Disposition 用 RFC 5987 编码文件名
