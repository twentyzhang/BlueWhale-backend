请在 com.twentyzhang.BlueWhale.util 包下创建 AuthUtil 工具类，
提供以下静态方法，均从 SecurityContext 中读取当前用户信息：

- getCurrentUser()：返回 AuthUser，未登录则抛出 BusinessException（code 401）
- getCurrentUserId()：返回当前用户 id
- requireRole(String... roles)：校验当前用户角色是否在允许列表中，
  不满足则抛出 BusinessException（code 403，message "权限不足"）
- requireStoreAccess(Long storeId)：校验当前 Staff 用户的 storeId
  是否与传入的 storeId 一致，不一致则抛出 BusinessException（code 403）

商品模块（分无鉴权和需要鉴权的操作，因此分两次提示） 


请实现 ProductServiceImpl 中以下无需登录的查询方法，
参考 docs/api-spec.md 中商品浏览相关接口定义：

1. listStoreProducts（GET /api/stores/{storeId}/products）：

   - 商店不存在则抛出 BusinessException（code 404）
   - 支持以下可选筛选条件：categoryId、keyword（商品名称模糊匹配）、
     minPrice、maxPrice
   - 分页返回，响应字段：id、name、price、stock、imageUrl、categoryName
2. getProductDetail（GET /api/products/{productId}）：

   - 商品不存在则抛出 BusinessException（code 404）
   - 响应字段：id、name、price、stock、imageUrl、
     category（id/name/parentId/parentName）、
     storeId、storeName、averageRating、reviewCount
   - averageRating 和 reviewCount 从 review 表关联查询
3. searchProducts（GET /api/products）：

   - 支持以下可选筛选条件：keyword、categoryId、minPrice、maxPrice
   - 分页返回，响应格式同 listStoreProducts
   - keyword 和 categoryId 均为空时正常返回全部商品（分页）



请实现 ProductServiceImpl 中以下需要鉴权的管理方法，
参考 docs/api-spec.md 中商品管理相关接口定义：

1. createProduct（POST /api/stores/{storeId}/products）：

   - 仅 Staff，使用 AuthUtil.requireRole("STAFF") 校验
   - 使用 AuthUtil.requireStoreAccess(storeId) 校验只能操作本店商品
   - categoryId 对应分类必须存在，否则抛出 BusinessException（code 404）
   - 返回新建商品的 id
2. updateProduct（PUT /api/stores/{storeId}/products/{productId}）：

   - 仅 Staff（本店）
   - 商品不存在则抛出 BusinessException（code 404）
   - 只更新请求体中传入的字段，未传入的字段不修改
   - 如果传入 categoryId，需验证分类是否存在
3. deleteProduct（DELETE /api/stores/{storeId}/products/{productId}）：

   - 仅 Staff（本店）
   - 商品不存在则抛出 BusinessException（code 404）
   - 该商品存在未完成的订单时不允许删除，抛出 BusinessException
     （提示：状态不为 COMPLETED 或 CANCELLED 的订单）
4. updateStock（PUT /api/stores/{storeId}/products/{productId}/stock）：

   - 仅 Staff（本店）
   - 商品不存在则抛出 BusinessException（code 404）
   - type 为 OUT 时，如果库存不足则抛出 BusinessException
   - 返回操作后的当前库存 currentStock
